Privacy policy – Clipping Engine

Last updated: November 20, 2026

What Google user data the app accesses

The app requests only the Google Drive scope https://www.googleapis.com/auth/drive.file. It can access only the files and folders that the app itself creates in the studio's own Google account: finished video clips and their transcripts. It cannot see any other Drive file.

How the data is used

The app uploads clips and transcripts to a "Clips" folder so the studio can review them. Nothing else is done with Google user data. It is not sold, not shared with third parties, not used for advertising, and not used to train AI models.

Storage and security

The authorization token is stored only as an encrypted secret in the studio's private GitHub repository and in the private processing job that uses it. It is never shown in logs.

Retention and deletion

Files stay in the studio's Drive until the studio deletes them. Access can be revoked at any time at myaccount.google.com/permissions, which stops the app from reaching Drive.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
